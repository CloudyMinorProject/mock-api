# Startup

## Using Terminal

1. Open terminal or VSCode terminal.

2. First fetch all NuGet dependencies:

```
dotnet restore
``` 

3. Build the project __after__ dependencies fetched:
```
dotnet build
```

4. Running the Project:

- You can run though the Terminal:
```
dotnet run
```

- Or using VSCode, Run Button top right _(Default)_
